# 本機字幕助手

這個資料夾提供 Windows 使用的一鍵啟動版本，讓 GitHub Pages 網頁可以連線到本機服務處理需要後端能力的工作。

## 第一次使用

1. 先安裝 Python 3.11 以上版本
2. 雙擊 `雙擊啟動本機助手.bat`
3. 等待套件安裝完成
4. 視窗顯示 `http://127.0.0.1:8765` 後，不要關閉它
5. 回到網頁按「檢查本機助手」

下載完成的影片會放在 `local-helper/downloads`。

如果啟動失敗，視窗會停在錯誤訊息畫面，請把畫面截圖提供給協助者。

## 使用提醒

YouTube 下載功能請限定用於自己的影片、已取得授權的影片，或平台明確允許下載的內容。
